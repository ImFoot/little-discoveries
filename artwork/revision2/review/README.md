# Target context review

These diagnostic sheets show every new target with its final reveal contour over source pixels. Each annotation records the completed source/context visual review; the sheets preserve that geometry for future inspection. They are not additional scenes or game artwork. Canonical source annotations remain authoritative. Physical iPhone/player acceptance is separate and pending. Regenerate with `node scripts/review-targets.mjs --archive 51 52 … 100` after any geometry change.
